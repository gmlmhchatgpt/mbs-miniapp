MBS Bond Mini App API (Phase 1) (1.0.0)

Download OpenAPI specification:

Đặc tả API cho Mini App Trái phiếu MBS tích hợp trong MB Bank (BeeRich). Tổng hợp từ tài liệu "Phạm vi phát triển (Phase 1)" — 35 API — và mapping với các màn hình webapp (mbs-miniapp). Các endpoint đánh dấu "(TBD)" trong mô tả là path đề xuất tạm thời, cần MBS/MB core xác nhận trước khi triển khai.
